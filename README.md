**Personal website and project catalogue, written by hand.**

Personal website for Carlos Martínez: backend development, classic games, video tools and the Suifuto Remon automotive project.

Built with HTML, CSS and a small JavaScript enhancement. No framework, external fonts, analytics or runtime dependencies. Project entries are generated as static HTML and remain available without JavaScript or browser requests to GitHub.

🌐 **Website:** https://evilchuck666.github.io/

## ✨ Features

- Biography, featured work and the complete catalogue of public projects.
- The catalogue syncs itself with GitHub every six hours: new repositories are
  added and removed ones disappear, with no manual edits.
- Accessible category filters and four-card pagination.
- The full catalogue stays visible without JavaScript.
- Responsive dark design with reduced-motion support.

## 🚀 Getting started

Open `index.html` directly in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
